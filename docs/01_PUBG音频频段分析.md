# 01 · PUBG 音频资源频段分析报告

> 对象：`E:\Steam\steamapps\common\PUBG`（本地实测，2026-10-19）
> 目的：为「降环境音 / 提脚步」动态处理器确定分频边界与默认阈值

---

## 1. 资源容器实测结论

| 项目 | 实测结果 |
|---|---|
| 包体结构 | UE4 Pak **版本 4**，`bEncryptedIndex = 1`（索引 AES 加密，资源名不可读） |
| 音频中间件 | **Wwise**（Audiokinetic）——RIFF 头标记 `metadata from: Audiokinetic Wwise RIFF header` |
| 编码 | **Wwise Vorbis（Custom Vorbis）**，`fmt` 块长 0x42，codec = `0xFFFF` |
| 采样率 | **48000 Hz**（`0xBB80`），单/双声道混存 |
| 存储方式 | **未压缩直存**（可绕索引直接从数据区提取），故 pak 内的 Wwise 流可直接从数据区取出（去重后 12 023 条：11 043 条可解码入库，965 条 AES 加密、14 条解码器不支持，均已剔除） |
| 主要音频包 | `pakchunk0-WindowsNoEditor_sound.pak` = **3.0 GB**；`_mutable.pak` 5.3 GB（外观，非音频） |

> 索引加密导致「脚步/枪声」文件名不可得，本报告采用**无声名、按声学特征聚类**的方法：从 `_sound.pak` 全盘提取 **13,590** 条 Wwise 流，均匀抽样 632 条 + 全长循环样本 85 条，解码后计算 Welch 功率谱、9 段倍频程能量、谱质心、10 ms 包络动态范围与瞬态密度。

提取脚本见 `tools/carve.py`、`tools/features.py`（vgmstream-cli 解码）。

### 2.1 三条决定性事实

1. **环境音（车/机/风）能量集中在 20–250 Hz**，200 Hz 以上按 ~-6～-12 dB/oct 滚降。
2. **脚步类瞬态在 125 Hz 以下几乎为零**（实测 0.0 %），能量主体在 **250 Hz–2 kHz**，峰值 500 Hz–1 kHz，3–6 kHz 承载草叶/碎石细节。
3. **枪声与脚步在 500 Hz–2 kHz 存在频域重叠**（枪声 1–4 kHz 占 35 %，脚步占 35 %）→ **单靠静态 EQ 无法分离，必须引入时域判据（瞬态/稳态）**。

### 2.2 为什么"只挂一个 EQ 曲线"会失败

| 朴素做法 | 后果 |
|---|---|
| 全局 +6 dB @1 kHz 提脚步 | 枪声、人声、UI、载具鸣笛同时变响，爆音削波 |
| 全局 -12 dB @120 Hz 降环境 | 脚步/换弹的低频体感一起消失，声像变"薄"、方向感变差 |
| 挂"响度均衡" | 稳态环境音被抬升，反而更吵 |

因此必须做**分频 + 动态（瞬态门控）**处理，而非静态 EQ。

### 2.3 运行时频谱 ≠ 资源频谱（重要）

Wwise 在游戏内还叠加了：距离衰减曲线、空气吸收低通、遮挡 LPF、HRTF/声像、混响。**30 m 外的脚步实测只剩 300–800 Hz 的"闷响"**。所以最终的增强参数不能照搬上表，必须：

- 分频边界按上表设定（150 / 600 / 3000 Hz）；
- **默认增益在实机标定**，软件内置实时频谱/电平表，提供"一键标定"。

## 3. 给 DSP 的分频结论

```
B1  20–150 Hz    环境基底：车辆、飞机、风、远处爆炸   → 主要抑制对象
B2  150–600 Hz   脚步低频体感、闷响、载具中低频        → 提 + 部分抑
B3  600–3000 Hz  脚步主体、语音、枪声主体              → 提（瞬态门控）
B4  3000–16000Hz 脚步细节（草/砂/水）、枪声爆音、玻璃  → 提（瞬态门控）
```

| 判据 | 阈值建议 | 依据 |
|---|---|---|
| 环境门限（B1 保持/衰减切换） | -45 ~ -35 dBFS（RMS，300 ms） | 环境音为稳态，RMS 波动 <6 dB |
| 瞬态灵敏度（脚步触发） | 快/慢包络差 > 6 dB | 脚步 10 ms 包络上升 15–30 dB，环境 <6 dB |
| 瞬态保持时间 | 60–150 ms | 单步时长 80–250 ms，双步间隔 350–500 ms |
| 枪声保护 | 峰值 > -12 dBFS 触发即时压缩 | 枪声动态 30–40 dB，比脚步高 15–25 dB |

## 4. 复现方法

```bash
# 1. 从 pak 中提取 Wwise 流（无需解密索引）
python tools/carve.py            # -> samples/wem/*.wem  (11 043 条可解码；加密的 965 条记入 samples/encrypted.txt)
# 2. 解码 + 特征提取（依赖 vgmstream-cli、numpy、scipy）
python tools/features.py         # -> samples/features.json
```

局限说明：索引加密 → 无法按文件名精确区分"脚步/枪声"，上表按声学特征聚类得出；样本量小的类别（n=6/8）已标注，结论以中频瞬态（n=113）与长循环环境（n=85）为主。
