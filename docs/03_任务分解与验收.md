## 3. 测试方案

### 3.1 延迟（硬指标）

1. `SignalGen` 输出 1 kHz 短脉冲（5 ms）到 CABLE Input（模拟游戏）。
2. 声卡"立体声混音"或第二块声卡录回真实输出。
3. 互相关求峰值位置 → `Δt = lag / fs`。
4. 50 次取样：报均值 + P95 + 抖动。
5. 判定：Mode A 均值 ≤ 20 ms、抖动 < 3 ms；Mode B ≤ 4 ms。

### 3.2 CPU / 内存

- PerfMon：`Process\% Processor Time`（音频进程）、`Private Bytes`，10 min 采样。
- ETW：`Microsoft-Windows-Audio` 检查 glitch 事件计数（目标 0）。

### 3.3 音质（盲测）

- 素材：PUBG 训练场 3 类场景各 20 段（野外脚步、城区脚步、载具+飞机）。
- A/B 盲测 10 人：评分"脚步可辨识度"、"枪声舒适度"、"环境压抑感"（1–5 分）。
- 通过线：脚步可辨识度 ≥ 4.0，枪声舒适度 ≥ 3.5，无人报告"头晕/泵感"。

### 3.4 回归

- DSP 单测 + 固定音源黄金样本（输出 PCM 哈希），防止参数改动引入退化。
