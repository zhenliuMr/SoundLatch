# SoundLock — PUBG 音频后处理器

Windows 实时音频处理：**降低环境音 / 强化脚步声** + **输出限幅**，两个开关，阈值全可调。

- 单文件 `SoundLock.exe`（约 146 KB），无安装、无运行库依赖
- 32 位浮点内部处理，48 kHz
- 音频处理线程 CPU **0.4 %**（单核），进程内存 **17.7 MB**
- 实测链路延迟见下表

---

## 1. 快速开始

### 1.1 路由（必须做一次）

```
PUBG  →  CABLE Input   （游戏内音频输出设备选它）
              │
        [ VB-Cable 虚拟声卡 ]
              │
        CABLE Output   （本程序采集）
              │
        SoundLock.exe
              │
        你的耳机 / 音箱   （本程序输出）
```

1. 装 VB-Cable：右键 `install_vbcable.bat` → 以管理员身份运行 → 重启
2. 游戏里把「音频输出设备」设为 `CABLE Input`
3. 打开 `SoundLock.exe`：采集选 `CABLE Output`，输出选你的耳机
4. 点「启动」

> 没有 VB-Cable 时可勾选「回环捕获」做无驱动测试：此时采集的是**当前默认输出**，
>   
> 请把「输出」选成**另一块设备**，否则会自己录自己。

### 1.2 两个开关

| 开关              | 作用                                         | 可调项                                                       |
| --------------- | ------------------------------------------ | --------------------------------------------------------- |
| ① 降低环境音 + 强化脚步声 | 4 段动态处理：20–150 / 150–600 / 600–3k / 3k–16k | 环境抑制量 0–100%、环境阈值 −60…−18 dBFS、脚步增强 0…+12 dB、瞬态灵敏度 0–100% |
| ② 锁定最大输出        | 前视砖墙限幅，超阈值即压，不超不动                          | 天花板 −24…0 dBFS                                            |

- 参数改动**立即生效**，自动存到 `%APPDATA%\SoundLock\config.ini`

### 1.3 调参建议（PUBG）

| 场景       | 建议                                         |
| -------- | ------------------------------------------ |
| 野外听脚步    | 环境抑制 60–75%，环境阈值 −45 dBFS，脚步 +8 dB，灵敏度 70% |
| 城区/房区    | 环境抑制 40–55%，阈值 −38 dBFS（枪声多，别压太狠）          |
| 载具/飞机噪音大 | 环境抑制 85%，阈值 −30 dBFS，脚步 +10 dB             |
| 嫌枪声炸耳    | 开关②天花板 −6 ~ −9 dBFS                        |

## 2. 实测数据（本机，2026-10-19）

| 指标     | 数值           | 说明                                             |
| ------ | ------------ | ---------------------------------------------- |
| 链路延迟   | **63–79 ms** | 采 22 + 缓冲 25 + 放 22 + 前视 1.5（本机端点各 22 ms，硬件下限） |
| 端点缓冲   | 22 ms / 端    | 探测结果：所有端点固定 1056 帧（`tools/lat_probe.exe`）      |
| 欠载     | ~2–3 次/秒     | 见下方「已知问题」，源于虚拟声卡内部采样率 96 kHz                   |
| 进程 CPU | 2–3 %（单核）    | 含 UI；DSP 本体 0.38 %                             |
| 内存     | 17.7 MB      | 工作集                                            |

> 本机两个端点的缓冲区被驱动固定为 22 ms（直连 Realtek 也一样），所以下限就是 44 ms。
>   
> **普通消费级主板/耳机的共享模式缓冲一般是 10 ms**，同样代码在那类机器上约 **25–30 ms**。
>   
> 想再低只有两条路：独占模式（本机驱动不支持 float 独占）或 APO 进音频引擎（见 `docs/02`）。

DSP 离线验收（`tests/dsp_test.exe`）：

```
[T1] 限幅器天花板 -6dB -> max 0.5012 (ceil 0.5012) PASS     零过冲
[T2] 分频平坦度 @1k: 0.01 dB PASS                            4 段求和
[T3] 60Hz -17.2 dB / 1kHz -0.5 dB PASS                       环境压、脚步带不动
[T4] 瞬态增强: +8.1 dB PASS                                  脚步类瞬态被抬起
[T5] 20 s 音频处理耗时 76 ms -> 0.38% of one core
```

## 3. 原理

```
输入 → 4 段 Linkwitz-Riley 分频(150/600/3000Hz，全通相位补偿)
     → B1 静态 -18dB + 向下扩展（压环境）
     → B2/B3/B4 瞬态门控向上扩展（提脚步），带电平保护防顶爆
     → 求和 → 前视限幅(单调队列求窗内峰值，零过冲) → 输出
```

频段依据来自对游戏内 13 590 条 Wwise 音频流的实测（`docs/01`）：
  
环境音 ~47 % 能量在 20–125 Hz，脚步瞬态 125 Hz 以下为 0、主体 250 Hz–2 kHz。

## 6. 常见问题

| 现象      | 处理                                                                                                                               |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 点了启动没声音 | 采集/输出选反了；采集必须是 `CABLE Output`（录音设备），输出是耳机                                                                                        |
| 游戏里没声音  | 游戏输出设成了 `CABLE Input`，但本程序没启动                                                                                                    |
| 有回声/啸叫  | 勾了「回环捕获」又把输出选成了正在采集的那块设备                                                                                                         |
| 爆音、卡顿   | 提高「环形缓冲」不可调时，先关掉其它占用音频的设备；蓝牙耳机不要用                                                                                                |
| 延迟显示很高  | 换有线耳机/独立声卡；蓝牙链路自带 100–200 ms                                                                                                     |
| 偶发轻微咔哒声 | 打开 `dist/vbcable/VBCABLE_ControlPanel.exe`，把 **Internal Sample Rate 改成 48000** 并重启系统；本机出厂是 96000，与 48 kHz 端点不匹配，会逼着引擎做 ±4 % 的重采样 |
| 脚步提升不明显 | 提高「瞬态灵敏度」，把「环境阈值」调到 −45 以下                                                                                                       |

## 7. 声明

只处理本机已输出的音频，不注入游戏进程、不读写游戏文件、不修改任何游戏内存。
  
PUBG 音频资源仅在本机做离线分析（提取 → 解码 → 统计），用于确定分频参数。
